## 十、下载方法

### Python SDK
```bash
pip install modelscope
```

```python
from modelscope.msdatasets import MsDataset

# 下载数据集
dataset = MsDataset.load('AI-ModelScope/alpaca-gpt4-data-zh', split='train')

# 保存为本地文件
for i, item in enumerate(dataset):
    with open(f'./data/alpaca_{i}.json', 'w', encoding='utf-8') as f:
        f.write(str(item))
```

### 命令行
```bash
pip install modelscope
modelscope download --dataset AI-ModelScope/alpaca-gpt4-data-zh --local_dir ./data/
```
