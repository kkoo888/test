## 五、本地知识库搭建讨论

### 5.1 用户提问
本地配了 Ollama，想离线也能查资料，怎么做？

### 5.2 小希回答：本地 RAG 方案

#### 整体思路
```
文档资料 → 切片 → 向量化 → 存入向量数据库
用户提问 → 检索相关内容 → 喂给 Ollama → 返回答案
```

#### 三种方案
| 方案 | 难度 | 上手时间 | 适合谁 |
|------|------|---------|--------|
| AnythingLLM | ⭐ | 10分钟 | 想快速体验 |
| Open Webui | ⭐⭐ | 15分钟 | 日常使用 |
| 自己搭 | ⭐⭐⭐ | 1-2小时 | 开发者 |

#### 自己搭的核心代码
```python
# 1. 加载文档
from langchain_community.document_loaders import DirectoryLoader
docs = DirectoryLoader("./knowledge/").load()

# 2. 切片
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)

# 3. 向量化（本地模型，离线可用）
embeddings = HuggingFaceEmbeddings(model_name="BAAI/bge-small-zh-v1.5")

# 4. 存入数据库
db = Chroma.from_documents(chunks, embeddings, persist_directory="./chroma_db")

# 5. 对接 Ollama
llm = Ollama(model="qwen2:7b")
qa = RetrievalQA.from_chain_type(llm=llm, retriever=db.as_retriever())
result = qa.invoke({"query": "你的问题"})
```

## 八、训练模型 vs 搭知识库

### 8.1 用户提问
这两个有什么区别？

### 8.2 小希回答

| 维度 | 训练模型（微调） | 搭知识库（RAG） |
|------|----------------|----------------|
| 本质 | 教 AI 学会技能 | 给 AI 参考书查 |
| 比喻 | 上学读书 | 考试带小抄 |
| 数据量 | 几万~几十万条 | 几份~几百份文档 |
| 成本 | 高（需要GPU） | 低（CPU就行） |
| 时间 | 几小时~几天 | 几分钟~几小时 |
| 效果 | 模型真的会了 | 模型靠查资料回答 |
| 更新 | 要重新训练 | 换文档就行 |

#### 建议
搭知识库更适合起步，先快速看到效果。路径：
```
先搭知识库（现在）→ 跑起来看效果 → 觉得不够 → 再训练微调（以后）
```

## 九、搭建知识库完整流程

### 9.1 用户提问
搭建全部流程有哪些？

### 9.2 小希回答：10 步流程

```
① 明确目标（5分钟）→ 想清楚 AI 要帮你回答什么
② 收集资料（30分钟~2小时）→ 把文档放一个文件夹
③ 文档预处理（30分钟）→ 清理乱码、确保能复制文字
④ 安装环境（10分钟）→ pip install + ollama pull
⑤ 文档切片（自动）→ 把长文档切成500字小块
⑥ 向量化（自动）→ 文字变数字向量
⑦ 存入数据库（自动）→ Chroma 持久化存储
⑧ 对接 Ollama（5分钟）→ 连接本地模型
⑨ 测试问答 → 验证效果
⑩ 优化迭代 → 调整参数提升质量
```

### 9.3 常见优化方案
| 问题 | 调整 |
|------|------|
| 找不到相关内容 | chunk_size 调小，TOP_K 调大 |
| 回答不完整 | chunk_size 调大 |
| 回答太啰嗦 | prompt 加限制 |
| 回答有幻觉 | 检查资料质量 |

### 9.4 时间预估
总计 2~4 小时搞定。

### 9.5 总结
```
1. 准备文档（你的资料）
2. 跑脚本（小希帮你写好）
3. 问问题（测试效果）
```
